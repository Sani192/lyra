# AI Knowledge Center

## Maturity Metadata

**Status:** Approved.

**Intended Use:** Authoritative index for AI-agent operating context and repository navigation.

## Canonical Naming Convention

The canonical AI Knowledge Center documents are the numbered Markdown files in this directory. AI agents must treat those numbered files as authoritative; unnumbered compatibility stubs exist only to redirect older links.

Unnumbered Markdown files in this directory are not canonical knowledge sources. They are retained only as redirects for backward compatibility and must point to one of the numbered documents above.
