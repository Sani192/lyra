# Diagrams Directory

## Maturity Metadata

**Status:** Approved.

**Intended Use:** Authoritative directory mapping for system graphics, structural diagrams, and visual flow definitions.

## Purpose

This directory acts as the central repository for storing design assets, raw graphic source files (e.g. Draw.io, Mermaid source), and rendered system architectures.

## Contents & Scope

This directory scopes:
* **Architecture Diagrams:** High-resolution renders of component layouts and system overview blocks.
* **Sequence & State Charts:** Mermaids and graphics representing conversational lifecycles, turn states, and capability call timings.
* **Source Assets:** Editable vector graphics and flow descriptions.
