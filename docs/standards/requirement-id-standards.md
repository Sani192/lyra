# Requirement Id Standards

## Purpose

Establish consistent requirement id standards for Lyra contributors and AI agents.

## Standard

* Follow `PROJECT.md` as the governing source.
* Prefer explicit, searchable names over abbreviations.
* Reference requirement IDs where behavior or architecture is affected.
* Update documentation before implementation.
* Preserve compatibility and document migration paths for breaking changes.

## Review Checklist

* Is the change aligned with Lyra's business-state boundary?
* Are affected specifications, ADRs, and examples updated?
* Are security, privacy, observability, and tenant isolation considered?
