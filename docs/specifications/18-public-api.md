# 18. Public API

## Maturity Metadata

**Status:** Draft.

**Intended Use:** Design specifications for public REST APIs.

## Purpose

Define the public REST API endpoints exposed by Lyra for session management and contract configuration.

## Scope

Covers public HTTP endpoints and parameters.

## Business Motivation

Allows developers to start and stop conversations and upload configurations programmatically.

## Assumptions

- APIs conform to REST standards.

## Dependencies

- None.
