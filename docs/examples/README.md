# Documentation Examples Index

## Maturity Metadata

**Status:** Approved.

**Intended Use:** Authoritative directory index for integration examples and domain blueprints.

## Purpose

This directory indexes and documents the domain-specific examples that demonstrate how consumer systems integrate with Lyra at runtime.

## Contents & Scope

This directory scopes:
* **Restaurant ordering blueprint:** Table check, reservation commits.
* **Clinic scheduling blueprint:** Slots checks, appointment bookings.
* **CRM lead intake blueprint:** Lead search, status upgrades.
* **Hotel booking blueprint:** Room check, confirmation events.
* **ERP invoice tracking blueprint:** Payment follow-up records.
